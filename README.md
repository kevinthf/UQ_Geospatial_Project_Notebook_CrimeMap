# UQ_Geospatial_Project_Notebook_CrimeMap
The project aimed to observe spatial and temporal patterns to identify trends in drug offences. Additionally, we would like to examine the correlation between the number of drug offences in mesh blocks (MBs) and local variables, such as dwellings, land use, distance to crime hotspots and the Index of Relative Socio-Economic Disadvantage (IRSD).
The aims of this project can be summarised as follows: </br>
⚫ Identify spatial and temporal patterns of drug offences in Logan Central from 2024 to 2025. </br>
⚫ Interpret the potential reasons for high numbers of drug offences by examining the characteristics of hotspot MBs by correlation analysis </br>
⚫ Examine the distance-decay relationship between crime hotspot MBs and their neighbouring MBs.
